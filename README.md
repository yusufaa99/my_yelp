# Welcome to My Backend Yelp
***

## Task
The goal of this project is to build a business listing and review platform like Yelp, where users can:

Add businesses
Write and read reviews
Make reservations
Favorite businesses
Search and filter businesses
Manage their profiles
All data is stored and managed with AWS Amplify, GraphQL API, and Amazon Cognito authentication.


## Description
This project provides a full-stack solution with the following technologies:

Frontend (React.js)
Built using React 18
Styled with Bulma CSS & Tailwind CSS
Uses React Router DOM for navigation

Backend (AWS Amplify & GraphQL)
AWS Amplify manages authentication and API requests
GraphQL (AWS AppSync) handles structured API calls
Amazon Cognito provides authentication

Features Implemented
✅ Authentication (Signup, Login, Logout with Cognito)
✅ Add & Edit Businesses (Name, category, location, images, etc.)
✅ User Reviews & Ratings
✅ Business Reservations (Users can book appointments)
✅ Favorites System (Users can save businesses)
✅ GraphQL API (CRUD operations for all entities)
✅ AWS Hosting with Amplify

## Installation
1️⃣ Clone the repository

$> git clone https://github.com/your-repo/my-backend-yelp.git
$> cd my-backend-yelp

2️⃣ Install dependencies

$> npm install

3️⃣ Set up AWS Amplify

$> amplify configure
$> amplify init
$> amplify push

4️⃣ Start the project

$> npm start
